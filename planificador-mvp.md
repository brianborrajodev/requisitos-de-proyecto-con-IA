
# StudyFlow: planificación del Producto Mínimo Viable

## Problema
Los estudiantes que gestionan varias asignaturas tienen dificultades para organizar sus tareas y controlar sus fechas de entrega. Como resultado, puede costarles identificar qué deben completar primero.

## Beneficio principal
Ayudar a los estudiantes a organizar sus tareas académicas en un único lugar y saber cuáles deben completar primero.

## Alcance del MVP
El MVP se limita a estas tres capacidades:
1. Crear tareas indicando nombre, asignatura y fecha de entrega.
2. Consultar las tareas pendientes ordenadas por fecha de entrega.
3. Marcar tareas como completadas.

## Flujo de usuario
1. El estudiante abre StudyFlow.
2. Registra una tarea indicando nombre, asignatura y fecha de entrega.
3. Consulta las tareas pendientes, ordenadas por fecha de entrega.
4. Marca una tarea como completada.

## Métrica de éxito
En una prueba con cinco estudiantes, al menos cuatro (80 %) completan sin ayuda el flujo completo: registrar una tarea, localizarla en la lista ordenada y marcarla como completada. Se considera «sin ayuda» si no reciben instrucciones ni pistas durante la prueba.

## Tecnologías sugeridas
No se impone una tecnología. Para un MVP de uso individual en un dispositivo, una aplicación web sencilla con almacenamiento local del navegador puede evitar servidores, cuentas e infraestructura adicional.
